2D Story-Driven Game (OOP Practice Project)

This repository holds a small 2D game project that started out as a school assignment. Since I ended up writing 95%+ of the code myself, I figured it deserved a proper spot in my personal portfolio.

About the Project

The main goal of this project was to teach myself how to practically apply Object-Oriented Programming  concepts. I wanted to see firsthand how OOP actually solves messy code problems, makes debugging less of a headache, and saves you from the super boring job of hunting down simple mistakes in a giant file.

Under the hood, the game is based on an original story and lore that my friend and I came up with a couple of years ago. Bringing our old story to life felt like the best way to make learning programming actually fun.

What I Learned

OOP in Action: Figuring out how to structure classes, handle encapsulation, and keep code modular instead of writing a massive procedural mess.

Debugging & Maintenance: Understanding why clean architecture makes fixing errors way easier when things break.

Game Loop & Logic: Managing basic game states, rendering, and player interaction from scratch.
